# Code of Conduct

MirrorPulse contributors are expected to communicate respectfully, focus on evidence, and keep reviews about the work. Harassment, discrimination, threats, doxxing, malicious disclosure of secrets, and deliberate disruption are not acceptable.

Maintainers may edit, reject, or remove contributions that violate this standard. Report concerns privately to the repository maintainer with relevant context and links. Do not include credentials, tokens, private paths, or user data in a report.

This document applies to repository discussions, issues, pull requests, reviews, and project communication.
